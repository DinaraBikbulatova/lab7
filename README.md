## Лабораторная работа 7 - Архитектура, слои и DDD-lite

### Архитектура:

- Domain Layer - чистая бизнес-логика без внешних зависимостей

- Application Layer - координация работы, use cases

- Infrastructure Layer - конкретные реализации (БД, API)

- DIP - Application зависит от интерфейсов, а не от реализаций

- DDD-lite - агрегат Order с инвариантами, Value Objects

### Архитектура позволяет:

- Легко тестировать бизнес-логику

- Менять реализации (БД, платежные системы)

- Соблюдать принципы SOLID

- Масштабировать систему
